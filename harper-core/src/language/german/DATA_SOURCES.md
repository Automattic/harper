# Where the German data comes from

`dictionary.dict` is **not** derived from igerman98 (GPL / hunspell `de_DE`).
It is generated by `scripts/build_german_dictionary.py` from the sources below,
so the German data can stay under Harper's Apache-2.0 licence.

| Data | Source | Licence |
| --- | --- | --- |
| Nouns, verbs, adjectives, forms, genders, plurals, word weights | [Wikidata lexemes](https://www.wikidata.org/wiki/Wikidata:Lexicographical_data) (German dump, via `scripts/extract_wikidata_lexemes.py`) | CC0 |
| Proper names (`wikidata_names.tsv`) | Wikidata items via SPARQL (`scripts/fetch_wikidata_names.py`) | CC0 |
| Compound begin forms (`compound_begin_forms.txt`) | Wikidata noun lexemes (`scripts/extract_german_compound_begin_forms.py`) | CC0 |
| Closed classes, curated words, irregular verbs (`scripts/german_closed_classes.py`, `scripts/german_curated.py`) | Written for Harper | Apache-2.0 |
| Affix rule tables (`annotations.json`, `scripts/german_affixes.py`) | Written for Harper | Apache-2.0, see caveat |

CC0 data needs no separate licence; the sources are named here and in the
header of `dictionary.dict`. No share-alike data is committed.

## Rebuilding

```bash
python3 -I scripts/extract_wikidata_lexemes.py ...   # dump -> SQLite, kept outside the repo
python3 -I scripts/build_german_dictionary.py --lexemes de3.db --out dictionary.dict
```

## Caveat: the affix tables

The 17 affix flags whose descriptions in `annotations.json` say
"Mirrors hunspell de_DE …" were modelled on the shape of the hunspell rules
(German inflection endings, which are linguistic facts). No igerman98 *word data*
is included, but a legal review, or re-deriving these tables from Wikidata forms,
is still open.

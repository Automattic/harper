## The Workflow (Step-by-Step)

### Step 1: Identify Unknown Words
```bash
# Run test on an article and capture unknown words
just language-test german "$(cat article.txt)" 2>&1 | grep -A 100 "Unknown words"
```

### Step 2: For Each Unknown Word

**Decision Tree**:

```
Is the word in hunspell?
   │
   ├── NO → Is it a proper noun or rare word?
   │        │
   │        ├── YES → Add with appropriate flags
   │        │
   │        NO → Can it be generated from existing words?
   │                 │
   │                 ├── YES → It's redundant, skip it
   │                 │
   │                 NO → Add explicitly
   │
   YES → What flags does hunspell use?
         │
         ├── Check: grep "^word/" /usr/share/hunspell/de_DE.dic
         │
         └── Map to Harper flags (see Flag Mapping below)
```

**Check if word is in Harper**:
```bash
just language-meta german "word"
# If NOT found → word is missing
# If found but wrong POS → flags need fixing
```

**Check if word can be generated** (compound or inflection):
```bash
# For compounds: Check if parts exist with compound flags
just language-meta german "part1"
just language-meta german "part2"
# If both have h/i/k/l/m/o/q flags → can be generated

# For inflections: Check if base form has declension flags
just language-meta german "baseform"
# If base has J/OQRSTUW or N/X/Y flags → inflection can be generated
```

### Step 3: Apply Fixes

**A. Add Missing Word** (only if not generatable):
```bash
# Find alphabetical position
grep -n "^word" dictionary.dict
# Insert at correct line (alphabetically sorted)
sed -i 'LINEi\newword/~~FLAGS' dictionary.dict
```

**B. Fix Incorrect Flags**:
```bash
# Replace flags on existing entry
sed -i 's|^word/.*|word/~~CORRECT_FLAGS|' dictionary.dict
```

**C. Remove Redundant Entry**:
```bash
# First verify it's still recognized after removal (via compound/FST)
sed -i '/^word\//d' dictionary.dict
just language-meta german "word"  # Should still be found
```

### Step 4: Verify
```bash
# Re-test the article
just language-test german "$(cat article.txt)"

# Check specific words
just language-meta german "word"

# Monitor metrics
just language-efficiency german
```

### Step 5: Repeat
Continue until no more unknown words, then move to next article.

**Commit after 5-10 iterations** (not after each word).

## Flag System Reference

### POS Property Flags (Uppercase)

| Flag | Meaning | Use When |
|------|---------|----------|
| `N` | Noun | Word is a noun |
| `M` | Masculine noun | Masculine gender |
| `F` | Feminine noun | Feminine gender |
| `Z` | Neuter noun | Neuter gender |
| `V` | Verb | Word is a verb |
| `J` | Adjective | Word is an adjective |
| `A` | Adjective (alias) | Alternative to J |
| `I` | Pronoun/Determiner | Word is pronoun or determiner |
| `R` | Adverb | Word is an adverb |
| `g` | Past participle | Verb form: past participle |
| `t` | Past tense | Verb form: past tense |

### Affix/Declension Flags (Uppercase)

| Flag | Meaning | Generates |
|------|---------|----------|
| `O` | Adj declension -e | Fem/Neut nom/acc sg |
| `Q` | Adj declension -em | Masc/Neut dat sg |
| `R` | Adj declension -en | Plural, genitive |
| `S` | Adj declension -er | Masc nom sg |
| `T` | Adj declension -es | Neuter nom/acc sg |
| `U` | Comparative | -er |
| `W` | Superlative | -sten |
| `X` | Noun plural -e | Feminine plurals |
| `Y` | Noun plural -n/-en | Various plurals |

### Compound Formation Flags (Lowercase)

| Flag | Meaning | Use When |
|------|---------|----------|
| `h` | No interfix | Word can compound without interfix |
| `i` | -s interfix | Word can compound with -s- |
| `k` | -n interfix | Word can compound with -n- |
| `l` | -en interfix | Word can compound with -en- |
| `m` | -er interfix | Word can compound with -er- |
| `o` | -es interfix | Word can compound with -es- |
| `q` | Adjective compound | Word can start adjective compounds |

## Common Flag Combinations

| Word Type | Flags | Example | Notes |
|-----------|-------|---------|-------|
| Adjective (base) | `JOQRSTUWq` | `rot/~~JOQRSTUWq` | Full declension + compound |
| Adjective (no compound) | `JOQRSTUW` | `gut/~~JOQRSTUW` | Full declension only |
| Adjective + adverb | `RJOQRSTUWq` | `schnell/~~RJOQRSTUWq` | Many adj can be adverbs |
| Adjective compound | `JOQRSTUWqh` | `mehrspurig/~~JOQRSTUWqh` | For compound adjectives |
| Past participle (adj) | `JOQRSTUWVg` | `verandert/~~JOQRSTUWVg` | Verb form as adjective |
| Noun (masc) | `Mh` | `Mann/~~Mh` | With compound capability |
| Noun (fem) | `Fh` | `Frau/~~Fh` | With compound capability |
| Noun (neut) | `Zh` | `Kind/~~Zh` | With compound capability |
| Noun (unknown gender) | `Nh` | `Haus/~~Nh` | With compound capability |
| Determiner | `Ih` | `alle/~~Ih` | Determiner/pronoun |
| Verb (base) | `V` | `sein/~~V` | Infinitive |
| Verb (conjugation) | `Vcej` | `machen/~~Vcej` | Full conjugation |
| Adverb | `R` | `sehr/~~R` | Pure adverb |

**Note on `R` flag**: In German, many adjectives can also function as adverbs. Use `R` + `J` when the word is commonly used both ways.

## When to Add Explicitly vs. Rely on Generation

### Add Explicitly When:
1. Word is in hunspell
2. Compound mechanism gives wrong metadata
3. Word needs specific flags that enable required declensions/compounds
4. Word appears in real text and cannot be generated properly

### DO NOT Add When:
1. Word can be generated via compound from existing words
2. Word is an inflected form of a base word with proper declension flags
3. Word would be redundant

**Rule of thumb**: If `just language-meta german "word"` returns the correct POS *after* removing the explicit entry, it was redundant.

### Pattern 3: Words with Incorrect Noun Flags (PRIORITY)

**Problem**: Word stems flagged as `~Nhpuvw` that are actually adjectives. The `N` flag (noun) combined with `puvw` (noun case flags) prevents proper adjective declension.

**Find all Pattern 3 entries**:
```bash

# Sample 20 entries

# Filter by common adjective suffixes (MOST PRODUCTIVE)
grep "~Nhpuvw" harper-core/src/language/german/dictionary.dict | grep -E "ig|lich|isch|bar|sam|weit|haft|voll|reich|arm|los|iv|al|ell|abel|ibel|är|or|ier" | head -30
```

**Automated Detection** (RECOMMENDED):
```bash

python .archive/german-language/scripts/fix_pattern3_nhpuvw.py
```

**Decision Tree for Pattern 3**:

```
Entry has Nhpuvw flags?
   │
   ├── Word ends in -ig, -lich, -isch, -bar, -sam, -weit?
   │        │
   │        ├── Check hunspell: grep "^word/" /usr/share/hunspell/de_DE.dic
   │        │
   │        ├── Hunspell has /A (adjective)?
   │        │        │
   │        │        YES → Pure adjective: Change to ~~~RJOQRSTUWqh
   │        │        (Add R for adverb capability if common)
   │        │
   │        ├── Hunspell has /S or /N (noun)?
   │        │        │
   │        │        YES → Adjective+noun: Change to ~~~NJOQRSTUWq
   │        │        (Keep N, add J for adjective declension)
   │        │
   │        NO → Use context: Is word used as adjective in text?
   │                 │
   │                 YES → ~~~RJOQRSTUWqh
   │                 NO → Investigate further
   │
   └── Word is a past participle (ge...t, ge...en)?
            │
            YES → Change to ~~~JOQRSTUWVg (past participle adjective)
            NO → Check if it's truly a noun (keep N) or adjective (remove N)
```

### Pattern 5: Adjectives Ending in -weit

## Troubleshooting

### "Word X recognized but inflected form Y not"

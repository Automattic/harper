# Atkinson Hyperlegible

The regular and bold fonts are shared by Desktop's settings/onboarding UI and non-macOS native egui overlays.
The macOS overlay uses the installed San Francisco font, falling back to Atkinson Hyperlegible if it cannot be read.

These unmodified files come from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible).
